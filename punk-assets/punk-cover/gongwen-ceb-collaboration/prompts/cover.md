# 品牌协同连接 cover prompt

You are a top-tier cover art director, editorial visual designer, product-brand visual designer, typography designer, and image-generation prompt director.

Create one single GitHub README hero banner for two companion AI Skills. Aspect ratio: 5:2. Compose one polished, wide, high-resolution raster image with generous breathing room and a clean enterprise-tool presentation.

The cover uses the selected visual style: 品牌协同连接 / brand-collaboration-connection. This is not a decorative filter. Every major decision must express two tools becoming one dependable document workflow.

## Input

- Logo A: the provided Gongwen avatar reference, a cobalt-blue square containing a white official-document page, vermilion header rule, black heading blocks, and a green verification mark
- Logo B: the provided CEB avatar reference, a pixel document stack with a blue conversion arrow leading to Markdown-like and PDF-like output pages
- Title/topic: 公文排版 × CEB 文件转换
- Title hierarchy:
  - A-layer / main visual title: 公文排版 × CEB
  - B-layer / complete meaning: 从旧格式读取，到规范排版
- C-layer / small text: DOCX · GB/T 9704-2012  ↔  PDF · Markdown · TXT
  - Place “PDF · Markdown · TXT” under the left CEB icon; place “DOCX · GB/T 9704-2012” under the right Gongwen icon.
- Platform: GitHub README
- Aspect ratio: 5:2
- Output dimensions: wide banner, preserve the 5:2 composition; no square crop
- Output mode: one single image
- Language: Chinese with short Latin file-format labels only
- Use case: the most prominent README image for two mutually linked open-source Skills
- Short context summary: CEB makes verified Founder CEB archives readable by converting them to PDF, Markdown, TXT, and reports. Gongwen turns Chinese formal materials into editable, verifiable DOCX layouts based on GB/T 9704-2012. They form a practical path from legacy material access to formal document delivery.
- Visual subject: two distinct skill icons on opposite sides, connected by one calm bidirectional bridge line and a small center node
- Audience: people handling Chinese enterprise, public-sector, and state-owned-enterprise documents with AI tools
- Mood: precise, trustworthy, modern, collaborative, restrained, quietly confident
- Visual metaphor: one continuous document workflow crossing a format boundary, with CEB on the left and Gongwen on the right
- Banned elements: unrelated logos, third-party product marks, people, mascots, office desks, screenshots, dashboards, flowcharts, many arrows, dense labels, fake certification seals, cyberpunk glow, excessive 3D, noisy textures, and unreadable microtext

## Content Understanding

At first glance the banner must show two companion document tools. At second glance it must make the relationship clear: CEB opens a legacy container into readable working material; Gongwen carries that material into a precise, editable Chinese official-document layout. Keep the visual relationship as one simple bridge, not a multi-step diagram.

## Cover Objective

Generate a deliberate GitHub project banner, not a generic illustration, software advertisement, presentation cover, or infographic. The two tools must remain distinct and recognizable while the connection is unmistakable. Use only the short title and compact format labels above; do not add paragraphs or invented product claims.

## Style Application

Translate both supplied avatar references into a matched pair of soft 3D rounded-square app icons while preserving their core visual cues. Place CEB on the left and Gongwen on the right. Use a single smooth bidirectional connector that transitions from CEB cyan-blue into Gongwen cobalt-blue and vermilion accents, with one small center node representing synchronization. Keep a light cool-gray-white background, a clean enterprise product feel, soft-neumorphic depth, restrained shadows, and large negative space. Do not create extra logos or alter either tool into an unrelated symbol.

The connector should feel like one stable bridge between legacy-file recovery and official-document formatting. It may be a gentle horizontal arc, but it must not pass through the title. Keep the visual language simple enough to remain legible when the GitHub banner is viewed on a narrow screen.

## Composition

- Primary visual center: the horizontal connector and its small center node
- Left anchor: CEB icon, slightly left of center, with the pixel document stack and conversion arrow still identifiable
- Right anchor: Gongwen icon, slightly right of center, with the white document, vermilion rule, heading blocks, and green verification mark still identifiable
- Secondary visual elements: one tiny synchronized node and restrained short format labels near each icon
- Background or space system: light gray-white, nearly flat, subtle cool ambient light, no grid or scenery
- Foreground/background layering: icons sit slightly above the background with soft controlled depth; connector runs behind the title area and between the icons
- Reading path: left CEB icon → center node → right Gongwen icon → lower-middle title
- Label mapping: left CEB icon = PDF · Markdown · TXT; right Gongwen icon = DOCX · GB/T 9704-2012.
- Shareability constraint: the relationship must read within one second; preserve wide empty margins and avoid tiny text stacks

## Image-Text Relationship

Treat the title as part of the product-system composition. Put “公文排版 × CEB” in the lower middle with a modern, bold, highly legible sans-serif treatment. Put “从旧格式读取，到规范排版” directly below in a smaller neutral weight. Keep format labels short and secondary. Do not let any text touch or overlap the connector or either icon. Preserve exact Chinese characters; if the renderer cannot form small labels reliably, omit the labels rather than inventing pseudo-text.

## Typography

Use a clean modern sans-serif suitable for a restrained enterprise product banner. The main title is dark charcoal with a very subtle two-color emphasis: “CEB” may use the left cyan-blue and “公文排版” may use the right cobalt-blue or a restrained vermilion accent. Keep the title complete and readable, with no distortion, crop, random letters, watermark, or decorative pseudo-Chinese.

## Color, Material, and Texture

Use a near-white cool-gray background, pale neutral surfaces, soft controlled shadows, CEB cyan-blue and deep navy accents on the left, and Gongwen cobalt-blue, vermilion red, black, and green accents on the right. The connector should carry a restrained cyan-to-cobalt transition. Use subtle rounded-square depth and clean edge highlights, not glossy toy material. No loud gradients, neon glow, heavy reflections, paper grain, noise, or decorative patterns.

## Negative Constraints

Avoid complex infographics, workflows with branches, charts, dashboards, UI screenshots, device mockups, people, mascots, extra logos, fake brand names, dense paragraphs, tiny unreadable text, oversized shadows, dark cyber backgrounds, neon glow, cheap gradients, crowded composition, cropped icons, distorted document shapes, or a generic stock-illustration look. Do not imply that every CEB file is supported; this is a visual introduction, not a technical guarantee sheet.

## Final Standard

Generate only one final 5:2 GitHub README hero banner. It must visibly use the brand-collaboration-connection language, keep CEB and Gongwen as two distinct but connected tools, preserve the two reference identities, maintain a light enterprise visual system, and leave enough quiet space for the title to remain readable. Do not output explanations, alternatives, grids, contact sheets, or multi-option compositions.
